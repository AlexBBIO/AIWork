      How to read this

      Jobs

      Each occupation is split into the tasks that fill its week. Open a group, then a job, to see which hours AI can take now and in the next two generations. Task mixes are estimates, so read the hours as rough.

      Show as

      Task types

      Every task in every job maps to one of these 29 types. Each is scored for how much of it the frontier model can do at professional quality, now and for the next two generations, up to a ceiling set by things intelligence can't change. Select a row for the evidence and sources behind it.

      Adjust the scoresTest your own assumptions. Changes stay in this browser, or share them with a link.

      Method and sources

      Snapshots

      One snapshot per Claude Opus release. Each scores what the best publicly available model could do on that date, which is not always the Opus model itself. Earlier snapshots were scored afterwards from benchmark results and are marked as backfilled. Abbreviations: GDPval, expert-graded comparison with professionals' deliverables; METR, length of task a model finishes on its own; RLI, Remote Labor Index, share of whole freelance projects done to professional standard; OSWorld, computer use.

      Checking the forecasts

      Each live snapshot's Frontier+1 and Frontier+2 forecasts are kept when it is retired, so the next snapshots can be scored against them.
