Method

Structure

Each occupation is split into tasks with a share of working time. Each task maps to one of 29 task types, and each task type gets a saturation score for three model tiers plus a ceiling.

Weights

Wage bill weights each occupation by employment times mean wage, so the index reads as a share of what employers pay for white-collar work. Jobs weights by headcount, so it reads as a share of people's working time.

Projection and limit

For each task type, the limit is the lower of its ceiling and the point where the Frontier to Frontier+2 trend flattens on its own. Past Frontier+2, the gap to that limit shrinks each generation by the ratio the last step implied.

The saturation point is the first generation that adds less than one point to the index.

Updating

Add a dated file to data/assessments/, list it in index.json, and run node scripts/validate.mjs. Occupation data lives in data/occupations.json.
